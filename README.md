## English Language
📝 About the Project
Site Maker 5700
 is a lightweight, fully client-side website builder using a simple 
drag-and-drop interface. The tool allows you to assemble simple web 
pages from ready-made blocks directly in your browser, customize their 
appearance, and export the result as a standalone HTML file.
The project is in Beta v1. This means the core functionality works, but many improvements and new features are on the way.
✨ Features
Drag-and-Drop: 7 ready-made components (Header, Hero, Image, Features, Form, Button, Footer).
Visual Editing: Adjust background color, text color, padding, and border radius for any element.
Code Editor: Add custom JavaScript to buttons (e.g., alert() or animations).
Forms: Send data to the console, via email (mailto), or a Webhook POST.
Image Upload: Insert images via URL or upload from your local file.
Dark Theme: Switch between light and dark UI themes.
Export: Save the finished page as a single .html file, ready for publishing.
Localization: Interface available in Russian and English.
🚀 How to Use
Download the Site Maker 5700.html file.
Open it in any modern browser (Chrome, Firefox, Edge, Safari).
Drag a component from the left panel onto the grey workspace (canvas).
Click on the added block to open its settings in the right panel.
Adjust the appearance, text, and behavior.
Click the «Export» button to save your website.

## Русский язык

### 📝 О проекте

**Site Maker 5700** — это лёгкий, полностью клиентский конструктор сайтов, работающий по принципу «перетащи и отпусти» (drag-and-drop). Инструмент позволяет собирать простые веб-страницы из готовых блоков прямо в браузере, настраивать их внешний вид и экспортировать результат в готовый HTML-файл.

Проект находится на **стадии Beta v1**. Это означает, что базовый функционал работает, но впереди много улучшений, исправлений и новых возможностей.

### ✨ Возможности

- **Drag-and-Drop:** 7 готовых компонентов (шапка, hero-секция, изображение, преимущества, форма, кнопка, подвал).
- **Визуальное редактирование:** Настройка цвета фона, текста, отступов и скругления для любого элемента.
- **Редактор кода:** Для кнопок можно добавлять собственный JavaScript (например, `alert()` или анимации).
- **Формы:** Отправка данных в консоль, на email (mailto) или через Webhook POST.
- **Загрузка изображений:** Поддержка вставки картинок по URL или из локального файла.
- **Тёмная тема:** Переключатель между светлой и тёмной темой интерфейса.
- **Экспорт:** Сохранение готовой страницы в один `.html` файл, готовый для публикации.
- **Локализация:** Интерфейс на русском и английском языке.

### 🚀 Как использовать

1.  Скачайте файл `Site Maker 5700.html`.
2.  Откройте его в любом современном браузере (Chrome, Firefox, Edge, Safari).
3.  Перетащите компонент из левой панели на серое поле (холст).
4.  Нажмите на добавленный блок, чтобы открыть его настройки в правой панели.
5.  Настройте внешний вид, текст и поведение.
6.  Нажмите кнопку **«Экспорт»**, чтобы сохранить ваш сайт.
